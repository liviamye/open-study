# dbbd-study

平板导航入口：豆包、百度等常用站

- [豆包 - www.doubao.com](https://www.doubao.com)
- [豆包聊天 - www.doubao.com/chat/](https://www.doubao.com/chat/)
- [百度 - www.baidu.com](https://www.baidu.com)
- [Kimi - www.kimi.com](https://www.kimi.com/) - 打开直接聊，长文本解析强，游客可用，适合读文档、代码、长资料
- [智谱清言 - www.chatglm.cn](https://www.chatglm.cn/) - GLM 大模型，游客模式可对话、简单画图，国内稳定
- [腾讯元宝 - yuanbao.tencent.com](https://yuanbao.tencent.com/) - 腾讯自研模型，游客直接发送提问（会先弹登录框，关掉后可用临时对话）
- [DeepSeek - www.deepseek.com](https://www.deepseek.com/) - 首页就有提问框，点“和 DeepSeek 对话”进网页版聊天
- [在线客服（QQ）](https://aganlaile.github.io/dbbd-study/qq.html)
